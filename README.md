# java-oop-management-systems
Colección de cinco sistemas de consola desarrollados en Java, aplicando POO, herencia, encapsulamiento, colecciones, manejo de excepciones, archivos y lógica de negocio para resolver diferentes escenarios de gestión.

## Sistemas desarrollados

| Sistema | Funcionalidades principales |
|---|---|
| 🏦 Cajero automático | Gestión de cuentas, depósitos, retiros, transferencias e historial de movimientos. |
| 🎓 Gestión académica | Registro de estudiantes, asignaturas, promedios y reportes. |
| 🛒 Tienda online | Catálogo de productos, inventario, compras y facturación. |
| 📒 Agenda de contactos | Registro, búsqueda, agrupación y persistencia de contactos en archivos. |
| 📊 Sistema de notas | Cálculo de promedios, aplicación de curvas de calificación y estadísticas. |

## Tecnologías y conceptos

- **Java**
- **Apache Maven**
- **Programación Orientada a Objetos:** encapsulamiento, herencia y polimorfismo.
- Colecciones y estructuras de datos.
- Validación de entradas y manejo de archivos.

## Ejecución

1. Clona o descarga este repositorio.
2. Abre el proyecto en **Apache NetBeans**.
3. Ejecuta la clase `Javapractica1.java`.
4. Selecciona uno de los cinco sistemas desde el menú principal.

## Sobre el proyecto

Proyecto académico compuesto por **5 ejercicios y 25 ampliaciones funcionales**, desarrollado para fortalecer los fundamentos de Java y la implementación de sistemas mediante POO.
